# SHOPKIT for Claude

Connect your own SHOPKIT shop to your assistant. Inspect your catalog and shop, prepare product and page drafts, and request owner review for changes to live content. Appointment access is a separate permission. Install this package, connect SHOPKIT, enter your enrolled shop address, then sign in on your shop and approve access. You can revoke the connection at any time in Studio.

An HTTPS shop running the matching SHOPKIT update is required. Directory publication is separate from installing this test package.
